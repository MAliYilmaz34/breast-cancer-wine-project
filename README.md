# 🧬 Machine Learning Analysis: Breast Cancer & Wine Datasets

This project is developed to perform exploratory data analysis, classification, and clustering on the **Breast Cancer** and **Wine** datasets, comparing the performances of various machine learning models.

---

## 📂 Project Structure

The file and directory structure of the project is organized as follows:

```text
├── FIGURES/                 # All generated analysis plots (PNG)
├── breast_cancer.ipynb      # Breast Cancer dataset analysis and modeling notebook
├── wine.ipynb               # Wine dataset analysis and modeling notebook
├── classifier_runs.csv      # Classification model run results
├── classifier_summary.csv   # Classification summary metrics
├── classifier_test.csv      # Final test classification results
├── kmeans_runs.csv          # K-Means clustering raw metrics
├── kmeans_summary.csv       # K-Means summary statistics
└── kmeans_test.csv          # K-Means final test evaluations
